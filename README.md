## v1.5.1 버그픽스 (2026-11-27)

**① 시작하자마자 진행률이 20%로 보이던 문제 (Stage 2~7 전부)**
- 원인: 전체 진행률을 `1단계 × 0.80 + 2단계 × 0.20`으로 계산하는데, **바닥 얼룩(2단계)이 없는 스테이지를 100%로 계산**해서 2단계 몫 20%가 그대로 더해졌습니다. Stage 7은 얼룩이 없어 `0% × 0.8 + 100% × 0.2 = 20%`로 시작했습니다.
- 수정: 실제로 존재하는 단계에만 가중치를 나눠 계산(`OverallCleanPercent`). Stage 2~7은 이제 **0%에서 시작**하고, 얼룩이 있는 Stage 1은 기존과 동일(80:20)합니다. 덤으로 시작 안개·조명도 20% 청소된 상태가 아니라 **완전히 더러운 상태**에서 출발합니다.

**② 우상단 의뢰 메모에서 `[ESC]`가 노란 메모 밖으로 삐져나오던 문제**
- 원인: `■ 의뢰 메모 [H] · 맵 [M] · 설정 [ESC]`를 14px 굵은 글씨 한 줄로 242px 박스에 넣어 폭이 약 250px 필요했습니다.
- 수정: 박스를 268px로 넓히고, 제목(좌)과 `[M] 맵 · [ESC] 설정`(우·11px)을 두 조각으로 분리해 박스 안에 정확히 들어가게 정리.

**③ Stage 7(6,000개) 진입 시 화면이 3초 넘게 멈칫하던 스폰 히치**
- 원인: 스테이지 진입 프레임 한 번에 6,000개 유닛을 생성(`SpawnForStage` 동기 루프)했고, 게다가 **Stage 1 규격 1,650개를 Awake에서 먼저 만들었다가 바로 버리는 이중 스폰**까지 있었습니다.
- 수정: ①Stage 1 선(先)스폰 제거(스테이지당 정확히 한 번) ②유닛 생성을 **프레임 예산(기본 5ms) 단위 코루틴**으로 분산 — 좌표·개수·난수 계산식은 기존과 동일해서 게임 규칙과 배치는 그대로입니다.
- 브라우저 콘솔창(F12)에 스테이지 진입·스폰 시작·스폰 완료 3줄이 찍힙니다(`[TrashCleaner3D] Stage 진입 … / 스폰 시작 … / 스폰 완료: 6,000개 · ○○ms`). 세 줄의 `t=` 값 차이로 **씬 로딩 / 스폰 / 첫 렌더** 중 어디서 멈추는지 확인할 수 있습니다.

**④ 1인칭 포인터 락 상태에서 하단 F1~F7 버튼이 눌리지 않던 문제**
- 원인: 포인터 락 중에는 마우스가 화면 중앙에 고정되어 하단 버튼 위에 커서를 올릴 수 없고, 클릭은 시선/흡입으로 들어갔습니다.
- 수정: **`Tab`(또는 `Alt`) = 커서 모드 토글**. 커서가 풀리면 하단 스테이지 버튼이 실제로 클릭되고, 다시 누르면 1인칭으로 복귀합니다. 포인터 락 중에는 눌리지 않는 버튼을 그리지 않고 `[M] 스테이지 맵 · [Tab] 커서 해제하면 하단 버튼 클릭 · F1~F7(PC)` 안내만 표시합니다.
- 커서 모드에서는 숫자 `1`~`7`로도 스테이지를 바꿀 수 있습니다(브라우저가 F5 새로고침·F1 도움말로 F키를 가로채는 문제 회피).

## v1.3 수거통 정산·통합 강화소·손맛 (2026-11-26)

**쓰레기 봉투를 없앴습니다 — 담으면 바로 트럭으로**
- 빨아들인 쓰레기는 **수거통**에 개수만큼 쌓입니다(봉투를 만들어 던지던 연출·모션 삭제, `ThrownTrashBag` 제거)
- 트럭 옆 **정산 구역**에 서서 `우클릭` 한 번이면 **1개만 담겨 있어도** 담긴 개수만큼 낱개 쓰레기가 트럭 적재함으로 우루루 쏟아지며 정산됩니다 (용량이 커도 가득 찰 때까지 기다릴 필요 없음)
- 수거통이 가득 차면 그때만 더 담기지 않고 `[RMB] 트럭 정산` 안내가 뜹니다

**강화는 트럭 옆 통합 강화소 한 곳에서만**
- 발판 3개 → **작업대(키오스크) 1대**로 통합, 앞에 서서 `E`를 누르면 강화 창이 열립니다
- `[Tab]` 상시 강화 트리와 우상단 `[Tab] 스킬트리` 버튼은 **삭제**
- 강화 14종으로 세분화: 흡입 속도 · 흡입 반경 · 수거통 용량 · 정산 단가 · 연속 정산 콤보 · 이동 속도 · 방독면 · 주먹 힘 · 걸레 성능 · 강력 세제 · **로봇 대수** · **로봇 속도** · 수거함 진입 · 자석 압축기

**초반 손맛 & 시야**
- 흡입 홀드: **1.00초**(맨손) → 1라운드 끝 무렵 0.25~0.20초 → 풀강 0.07초
- 흡입 반경: **0.15m(지름 30cm, 50원 동전 느낌)** 에서 시작 → 강화로 확장. 바닥 링은 y=0 평면에 고정되고 반경이 흔들리지 않습니다
- 흡입 도착점이 화면 중앙이 아니라 **1인칭 손/노즐 끝**으로 바뀌어 내 손으로 빨려 들어옵니다
- 악취: 4단계에서도 **작업은 계속 가능**(예전엔 완전 봉인). 대신 단계별 작업 속도 감소가 커지고 **화면이 뿌옇게 가려지는 안개**가 짙어집니다

**기타**
- 보유 현금을 좌상단 **진녹색·금테 배지(27px)** 로 분리, `+$` 팝업도 크게
- 큰 봉투 **체력바**가 때릴 때마다 0부터 차오르던 버그 수정 → 남은 체력에서 자연스럽게 깎임
- 5개 무더기 구역에 **바닥 색 매트 + 테이프 링**(주황·파랑·보라·초록·노랑)을 깔아 눈으로 구분
- 행주질 모션이 화면 구석 → **화면 중앙 앞쪽**으로 이동
- 로봇청소기: **시작 0대**(바닥에 없음) → 강화소에서 **로봇 대수를 처음 사면 1대 등장**, 이후 최대 3대까지 · 1초에 1개. **로봇 속도**는 1대를 보유해야 해금 (플레이어 주력의 보조)

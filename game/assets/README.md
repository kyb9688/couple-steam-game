# 에셋 전용 폴더 안내 (여자친구 디자인·아트 업로드 구역)

이 폴더는 **코드와 완전히 분리된 이미지·사운드 전용 공간**입니다.
정해진 하위 폴더와 파일명 규격(`docs/art/cozy-workshop-art-kit.md` 참고)에 맞춰 투명 배경 PNG를 넣어주시면 게임에 충돌 없이 반영됩니다.

- `scraps/` — 고물 17종 (예: `t1_radio_closed.png`, `t1_radio_open.png`)
- `parts/` — 부품·주괴 12종 (`128x128` PNG, 예: `copper_wire.png`, `gold_ingot.png`)
- `machines/` — 고정 슬롯 기계 5종 (예: `crusher_head.png`, `smelter_base.png`)
- `backgrounds/` — 공방 배경 4장 (`1280x720` PNG, `bg_t1.png` ~ `bg_t4.png`)
- `ui/` — 버튼·패널·스킬 아이콘·스팀 캡슐 시안
- `audio/` — CC0 / 상업 라이선스 효과음(`.wav` / `.ogg`)

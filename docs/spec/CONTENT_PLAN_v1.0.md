### 게임 시작 & 스테이지 공통 규칙 (파트 B 확정)
- **모든 스테이지 공통 시작 지점:** 모든 스테이지는 **현관문이 닫힌 상태**에서 **현관문 앞(바깥쪽)**에 플레이어가 서 있는 상태로 시작합니다. *(직접 문을 열고 들어가며 쓰레기집을 마주하는 연출!)*
- **시작 즉시 노출:** 게임 시작(또는 거점 허브) 시 **7개 스테이지 전체가 연결된 마인드맵(로드맵) 형태**로 한눈에 보이게 배치합니다.
- **순차 해금 & 상태별 색상 구별:** 앞 스테이지를 클리어해야 다음 스테이지가 열리며, 플레이어가 현재 진행 가능 여부를 1초 만에 구분할 수 있도록 색상을 분리합니다.
  - 🔒 **잠김 (이전 스테이지 미클리어):** 어두운 회색(`#64748B`) + 자물쇠 아이콘
  - ▶ **진행 가능 (현재 도전 단계):** 밝은 노랑/주황(`#F59E0B`) + 테두리 강조
  - ✅ **클리어 완료 (재방문 파밍 가능):** 에메랄드 초록(`#10B981`) + 별점(`★`) 표시
- **상황 이미지(썸네일) 삽입:** 각 스테이지 노드 카드 안에 해당 방 분위기를 직관적으로 보여주는 **상황별 일러스트/스크린샷 썸네일**을 함께 배치합니다. *(파트 B가 썸네일/아이콘 제작)*

## 3. 무료 1차 에셋 탐색 키워드 체크리스트 (실사 PBR · 1K~2K 통일)

> **규칙:** 프로토타입 2주 동안은 아래 무료 에셋으로만 원룸 1칸을 먼저 완성합니다. 다운로드 시 **1K 또는 2K** 해상도, **실사 PBR 톤(카툰/로우폴리 제외)**으로 통일합니다.

### ① Poly Haven (`polyhaven.com`) — 벽지·바닥·조명
- [ ] 벽지 (누런 아이보리/낡은 석고): `plaster`, `dirty plaster`, `wallpaper`, `painted wall`
- [ ] 원룸 바닥 (낡은 우드/장판): `wood floor`, `laminate floor`, `linoleum`, `worn planks`
- [ ] 현관·화장실 타일: `ceramic tiles`, `bathroom tiles`, `dirty tiles`
- [ ] 실내 기본 조명(HDRI): `indoor`, `room`, `fluorescent`, `interior`

### ② ambientCG (`ambientcg.com`) — 얼룩·곰팡이 데칼
- [ ] 바닥 얼룩 / 국물 자국: `stain`, `grunge`, `leaking`, `dirt`, `puddle`
- [ ] 벽 곰팡이 / 습기: `mold`, `moss`, `damaged plaster`, `concrete`

### ③ Fab (`fab.com` — Quixel Megascans 무료) & Sketchfab (`CC0`) — 쓰레기·보물
- [ ] 쓰레기 소품: `garbage bag`, `trash bag`, `cardboard box`, `pizza box`, `plastic bottle`, `soda can`, `debris`
- [ ] 테스트용 보물 3~5종: `gold ring`, `wristwatch`, `cash stack`, `game console`, `jewelry box`

### ④ 유료 팩 후보 찜 목록 (프로토타입 통과 후 2개만 선별 결제 검토)
- [ ] **원룸 가구 팩 (URP):** *Realistic Apartment Asset Pack* (~\$14.99) / *Abandoned Room* (~\$19.99) / *Apartment - Interior and Props* (~\$29.99)
- [ ] **쓰레기 소품 팩 (URP):** *Garbage and Trash Props* (~\$9.90) / *Garbage and Debris Vol. 1* (~\$12.99)

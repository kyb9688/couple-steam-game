## 5. 남은 검증(사용자 PC 필요)

1. Unity 에디터에서 1회 플레이: ST1 15~20분, ST7 60~80분 체감 확인.
2. WebGL 빌드에서 ST7(동시 6,500개) 프레임·스폰 히치 확인. 스폰은 프레임 예산 5ms로 분산되지만, 최초 웨이브 진입 시 수 초간 채워지는 것을 콘솔 로그(`웨이브 n/20 스폰 완료 …ms`)로 확인 가능.
3. 실제 손맛 기준으로 `1회 강화 상승폭`(1.5~3%)이 심심하면 `tree_v17.py`의 `per_level`만 올려 재생성하면 된다(시뮬레이터도 같은 값으로 다시 검증 가능).
